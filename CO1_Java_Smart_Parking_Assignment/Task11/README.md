## Task 11 – Parking-system implementation and tests

Compile and run from this folder:

```powershell
javac SmartParkingSystem.java
java SmartParkingSystem
```

The program demonstrates unique tickets, entry-time capture, fee calculation, a monthly pass, slot release/reuse, capacity limits, and checks for zero-minute stays, fee boundaries, invalid slots, duplicate registrations, and unknown vehicle types. See [the assignment report](../Assignment_Report.md) for the expected-versus-actual test table.
