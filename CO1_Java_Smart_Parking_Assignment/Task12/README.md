## Task 12 – Day-4 design challenge

Compile and run from this folder:

```powershell
javac DesignChallenge.java
java DesignChallenge
```

The program demonstrates an e-bike flat fee, a delivery van charged at double the car rate from 9 AM through 4:59 PM, a date-limited visitor one-day pass, and five floors with different slot counts. The output checks van pricing before, during, and after the special time window and checks pass validity on the following day.
