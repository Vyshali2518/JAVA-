# Programming in Java – Assignment 2 (CO2)

**Coverage:** Strings and StringBuilder, regular expressions, List, Queue, Deque, PriorityQueue, Set, Map, `hashCode()`–`equals()`, Generics, Comparable, Comparator and Collections utilities.

This repository is organised by the seven questions in the CO2 assignment. Each `Qn` folder contains Java source code and a task README. Compile and run each program from its folder:

```bash
javac *.java
java MainClassName
```

Use JDK 8 or later. Some programs use `System.nanoTime()` and report measurements from the machine on which they are executed. Timing values are environment-dependent; do not copy sample timings as experimental evidence. Run the programs repeatedly and record your own results for the report.

## Folder structure

- `Q1` – String, StringBuilder and StringBuffer comparison
- `Q2` – ArrayList, LinkedList and ArrayDeque operations
- `Q3` – hashCode–equals contract and HashSet de-duplication
- `Q4` – HashMap, TreeMap and LinkedHashMap inventory
- `Q5` – Generic leaderboard and comparator
- `Q6` – PriorityQueue triage
- `Q7` – Diagnose, redesign and validate

Add your name, register number, Java version, screenshots and raw experimental data before submission. The assignment requires individual execution and progressive Git commits.
